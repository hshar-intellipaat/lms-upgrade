# LearnPath Product Handoff

This directory contains implementation guidance for taking the LearnPath prototype into production.

- [Backend Developer Handoff](BACKEND_DEVELOPER_HANDOFF.md): domain model, APIs, progression and gamification rules, semester-reset batch rankings, security, scheduled jobs, testing, and acceptance criteria.
- [UI/UX Handoff](UI_UX_HANDOFF.md): information architecture, user flows, semester leaderboard states, responsive behavior, accessibility, research, and Figma deliverables.

The HTML and JavaScript files in the repository are prototypes. Where a document describes a production recommendation that differs from the prototype, the documented production recommendation should take precedence after product and academic approval.
